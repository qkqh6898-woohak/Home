# 대전 아파트 매수 타이밍 앱

대전 아파트 시장 데이터를 매일 모아 리포트를 만들고, 매수 적기인지를 점수와 근거로 보여주고,
추세를 그래프로 확인하는 개인용 앱입니다. 아이폰과 안드로이드에서 쓰고, 무료로 운영하는 것이 조건입니다.

이 저장소는 Claude Code 세션 세 번에 걸쳐 앱을 만듭니다. 세션마다 쓸 프롬프트가 `prompts/` 폴더에 있습니다.

## 진행 순서

| 순서 | 세션 | 프롬프트 | 하는 일 | 끝나면 생기는 것 |
|---|---|---|---|---|
| 1 | 기획 | `prompts/session1_planning.md` | 데이터 소스 조사, 판단 로직, 화면, 구조 설계. 코드는 작성하지 않음 | `docs/` 폴더의 기획 문서 10개 |
| 2 | 개발 | `prompts/session2_development.md` | API 키 없이 샘플 데이터로 앱 전체를 완성 | 동작하는 앱, `docs/API_SETUP.md`, `docs/PROGRESS.md`, `docs/USER_GUIDE.md` |
| 3 | API 추가 | 아직 작성 전 | API 키를 등록하고 샘플 데이터를 실제 데이터로 교체 | 실제 시장 데이터로 동작하는 앱 |

각 세션은 앞 세션이 저장소에 남긴 문서를 읽고 시작합니다. 그래서 세션은 반드시 이 저장소에서 열고,
앞 세션의 결과가 푸시된 뒤에 다음 세션을 시작해야 합니다.

## 1세션: 기획

**준비**

`prompts/session1_planning.md`의 "2. 내 조건"에 빈칸이 세 개 있습니다.

| 빈칸 | 예시 | 쓰이는 곳 |
|---|---|---|
| 연소득 | 부부 합산 9천만 원 | 대출 가능액(DSR) 계산 |
| 보유 자금 | 자기자본 3억 원 | 가격대별 필요 자금 계산 |
| 개발 경험 | 거의 없음, 코드는 Claude가 작성 | 기술 스택 추천 |

실제 금액을 파일에 적어 커밋하지 마세요. 세션 채팅에서만 알려 주면 됩니다.

**시작 메시지**

```
prompts/session1_planning.md를 읽고 그대로 진행해 줘.
빈칸은 이렇게 채워: 연소득 [ ], 보유 자금 [ ], 개발 경험은 [ ].
내 연소득과 보유 자금의 실제 숫자는 문서에 적지 말고, 예시 숫자나 변수로 표현해 줘.
```

**진행 중**

세션이 시작 전에 질문을 최대 5개 하고, 결정이 필요한 지점마다 선택지와 추천안을 제시합니다.
답을 주면 기획을 이어갑니다.

**끝났는지 확인**

`docs/` 폴더에 아래 파일이 모두 있어야 합니다.

| 파일 | 내용 |
|---|---|
| `PRD.md` | 서비스 개요, 기능 명세, 첫 버전 범위 |
| `DATA_SOURCES.md` | 지표별 데이터 소스, 수집 방법, API 키 발급 방법 |
| `SCORING.md` | 판단 지표, 가중치, 남은 기간에 따른 로직, 예시 계산 |
| `FINANCE.md` | 생애최초, 정책대출, DSR 기준과 가격대별 필요 자금 |
| `CANDIDATES.md` | 통근 30분 생활권과 후보 단지 |
| `TIMELINE.md` | 2030년 8월 기준 매수 경로별 역산 일정 |
| `GLOSSARY.md` | 경매, PF, 금융 용어 사전 |
| `ARCHITECTURE.md` | 구조도, 기술 스택, DB 구조, 자동 실행, 무료 한도 |
| `ROADMAP.md` | 개발 체크리스트 |
| `HANDOFF.md` | 2세션이 읽고 바로 시작할 수 있는 요약 |

## 2세션: 개발

**준비**

없습니다. 이 프롬프트는 채울 빈칸이 없고, API 키도 필요하지 않습니다.

**시작 메시지**

```
prompts/session2_development.md를 읽고 그대로 진행해 줘.
```

**진행 중**

세션은 확인을 기다리지 않고 `docs/ROADMAP.md`의 마일스톤을 순서대로 만듭니다.
기술 스택 교체나 기능 삭제처럼 되돌리기 어려운 변경이 필요할 때만 물어봅니다.
마일스톤이 끝날 때마다 휴대폰 화면 크기의 스크린샷과 한 줄 보고를 남기고 커밋합니다.

**결과물에 대해 알아 둘 점**

- 화면에 나오는 가격과 점수는 샘플 데이터입니다. 실제 대전 시장이 아니므로 매수 판단에 쓸 수 없습니다.
- 알림은 실제로 발송되지 않고, 보낼 메시지를 미리보기로만 확인합니다.
- API를 호출하는 코드는 작성돼 있지만 키가 없어 실행 확인을 하지 못한 "미검증" 상태입니다.

**끝났는지 확인**

- `docs/PROGRESS.md`에 완료한 것과 남은 것이 정리돼 있다
- `docs/API_SETUP.md`에 필요한 키 목록과 발급, 등록 방법이 있다
- `docs/USER_GUIDE.md`의 안내대로 휴대폰에 설치해 화면이 열린다

한 세션에 끝나지 않았다면 새 세션에서 아래 메시지로 이어갑니다.

```
docs/PROGRESS.md를 읽고 남은 마일스톤부터 이어서 개발해 줘.
진행 방식은 prompts/session2_development.md를 따라 줘.
```

## 3세션: API 추가

3세션 프롬프트는 아직 없습니다. 2세션이 끝나면 `docs/API_SETUP.md`와 `docs/PROGRESS.md`를 바탕으로 작성합니다.

**준비**

1. `docs/API_SETUP.md`의 키 목록을 보고 각 사이트에서 키를 발급받습니다. 승인에 며칠 걸리는 곳이 있으니 2세션이 끝나면 바로 신청해 두세요.
2. 발급받은 키를 문서에 안내된 위치에 직접 등록합니다. 키는 세션 채팅에 붙여넣지 않습니다.
3. 알림을 받으려면 텔레그램 봇 토큰도 같은 방식으로 등록합니다.

**하는 일**

- 소스별 "미검증" 수집 코드를 실제 API로 실행해 확인하고 고칩니다
- 샘플 데이터를 실제 데이터로 교체하고, 과거 데이터를 채웁니다
- 실제 데이터로 점수와 그래프가 맞게 나오는지 검증합니다
- 알림을 실제로 발송해 확인합니다

## 주의할 점

- **투자 자문이 아닙니다.** 이 앱의 점수와 리포트는 공개 데이터를 정해진 산식으로 계산한 참고 자료입니다.
- **개인 정보를 커밋하지 마세요.** API 키, 토큰, 소득과 자금의 실제 숫자는 저장소에 올리지 않습니다.
- **기준은 바뀝니다.** 정책대출 한도, 대출 규제, 데이터 제공처의 정책은 변경될 수 있으므로 실제 매수 전에 최신 기준을 다시 확인하세요.

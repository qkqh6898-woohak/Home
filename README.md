# 대전 집 타이밍

대전 아파트 매수 타이밍을 매일 점수와 그래프로 확인하는 개인용 앱입니다. 아이폰과 안드로이드에 설치해서 쓰는 PWA이고, 무료로 운영됩니다.

**앱 주소: https://qkqh6898-woohak.github.io/Home/**

> 지금은 샘플 데이터로 동작합니다. 화면의 가격과 점수는 실제 대전 시장이 아니며, 뉴스만 실제 데이터입니다.

## 동작 방식

`main` 브랜치 하나로 운영합니다.

- `main`에 푸시하면 GitHub Actions가 앱을 GitHub Pages에 배포합니다.
- 매일 아침 6시 23분(한국 시간)에 데이터를 다시 만들어 `main`에 커밋하고 배포합니다.
- 앱은 열 때마다 최신 파일을 받아 오므로 따로 업데이트할 필요가 없습니다. 오프라인이면 마지막으로 받은 화면을 보여줍니다.

## 화면

| 탭 | 내용 |
|---|---|
| 오늘 | 판단 점수, 근거, 매수 경로별 점수, 2030년 8월 기준 역산 일정 |
| 그래프 | 생활권별 매매가, 거래량, 전세가율, 금리, 경매, 미분양, 입주 물량, 점수 추이 |
| 지역 | 대덕연구단지 통근 30분 이내 후보 생활권 6곳 비교 |
| 자금 | 소득과 자기자본으로 가격대별 대출 한도와 월 상환액 계산 (기기에만 저장) |
| 더보기 | 뉴스, 데이터 상태, 설치 방법, 점수 계산 방식, 용어 사전 |

## 휴대폰에 설치

- 아이폰: Safari로 앱 주소를 열고 공유 버튼 → "홈 화면에 추가"
- 안드로이드: Chrome으로 앱 주소를 열고 메뉴(⋮) → "앱 설치"

## 실제 데이터로 바꾸기 (나중에)

저장소 Settings → Secrets and variables → Actions에 아래 이름으로 키를 등록하면, 다음 실행부터 해당 지표가 실제 데이터로 바뀝니다. 수집 코드는 키 없이 작성해서 아직 실행 확인을 하지 못했으므로, 처음 등록한 뒤에는 Actions 로그와 앱의 "데이터 상태"를 확인해야 합니다.

| Secret 이름 | 발급처 | 바뀌는 지표 |
|---|---|---|
| `DATA_GO_KR_KEY` | 공공데이터포털 "국토교통부 아파트 매매 실거래가 자료" | 생활권별 매매가, 거래량 |
| `ECOS_KEY` | 한국은행 ECOS Open API | 기준금리, 주택담보대출 금리 |

전세가율, 경매, 연체율, 미분양, 입주 물량은 아직 실제 수집 코드가 없어 샘플로 남습니다.

## 파일 구성

| 경로 | 내용 |
|---|---|
| `app/` | 앱 화면 (배포되는 폴더) |
| `app/data/data.json` | 매일 새로 만들어지는 데이터 |
| `scripts/update.py` | 데이터 수집, 점수 계산 |
| `.github/workflows/update.yml` | 매일 갱신과 배포 |
| `prompts/` | 처음 구상할 때 쓴 기획·개발 프롬프트 |

## 주의할 점

- 투자 자문이 아닙니다. 점수는 공개 데이터를 정해진 산식으로 계산한 참고 자료입니다.
- 통근 시간, 역산 일정, 대출 계산의 기본값은 가정값입니다. 실제 매수 전에 최신 시세와 대출 기준을 직접 확인하세요.
- API 키와 개인 재무 정보는 저장소에 올리지 않습니다.

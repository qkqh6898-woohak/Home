이번 세션은 "개발" 세션이야. 기획은 이전 세션에서 끝났고 결과가 docs/ 폴더에 있어.

## 1. 이번 세션의 범위
- 이번에는 API 키 없이 끝까지 만든다. API 연동은 나중 세션에서 추가할 거야.
- 목표: 키만 등록하면 실제 데이터로 바뀌는 상태의 완성된 앱.
  수집 → 저장 → 점수 계산 → 리포트 → 그래프 화면까지 전체 흐름이 샘플 데이터로 동작해야 해.
- 키 발급이나 등록을 나에게 요청하지 말고, 그 때문에 멈추지도 마.

## 2. 시작 순서
1) docs/HANDOFF.md를 먼저 읽고, 이어서 docs/ROADMAP.md, docs/ARCHITECTURE.md,
   docs/SCORING.md, docs/DATA_SOURCES.md를 읽어 줘. 나머지 문서는 필요할 때 참고해.
2) 이번 세션에서 만들 마일스톤 목록을 짧게 보고하고, 내 답을 기다리지 말고 바로 개발을 시작해 줘.
3) HANDOFF에 미결 사항이 있으면 추천안으로 정해서 진행하고, 무엇을 어떻게 정했는지 기록해 줘.

## 3. API 없이 만드는 방식
- 데이터 소스마다 수집기를 같은 형태(인터페이스)로 만들고, 구현을 두 개씩 둬.
  - 샘플 구현: 저장소에 넣어 둔 샘플 데이터를 읽음 (이번 세션에서 동작)
  - 실제 구현: API를 호출하는 코드. docs/DATA_SOURCES.md의 명세대로 작성하되
    키가 없어 실행 확인은 못 하므로 "미검증"으로 표시
- 키가 등록돼 있으면 실제 구현, 없으면 샘플 구현을 쓰도록 자동 전환되게 해 줘.
- 키가 필요 없는 공개 자료(공개 통계 파일, 뉴스 RSS 등)는 이용약관이 허용하면
  이번 세션에서 실제 데이터로 연결해도 돼.
- 샘플 데이터는 실제 API 응답과 같은 형식으로 만들고, 값은 대전 시세에 가까운 현실적인
  범위로, 그래프와 점수가 의미 있게 보일 만큼의 기간(예: 3년치)을 넣어 줘.
- 샘플 데이터로 만든 화면·리포트·점수에는 "샘플 데이터 (실제 시장 아님)" 표시를
  눈에 띄게 넣어 줘. 샘플 점수가 실제 매수 판단처럼 보이면 안 돼.
- 알림(텔레그램 등)도 토큰 없이 진행: 발송 코드는 만들어 두고,
  이번에는 보낼 메시지를 화면이나 파일로 미리보기만 해 줘.
- 매일 자동 실행 스케줄도 설정해 두되, 키가 없을 때 실패하지 않고 샘플 모드로 돌게 해 줘.

## 4. 개발 원칙
- 기획 문서의 결정을 따를 것. 바꿔야 할 이유가 생기면 이유와 대안을 기록하고,
  되돌리기 어려운 변경(스택 교체, 기능 삭제)만 나에게 먼저 물어봐 줘.
- 완전 무료 조건 유지: 유료 API, 유료 서버, 앱스토어 비용이 드는 선택은 하지 마.
- 키, 토큰, 내 소득·자금 같은 개인 정보는 저장소에 커밋하지 마.
  키는 secrets나 환경 변수로, 개인 재무 조건은 커밋되지 않는 별도 설정으로 분리해 줘.
- 판단 화면과 리포트에는 "투자 자문이 아님" 고지와 데이터 기준일을 항상 표시해 줘.

## 5. 마일스톤마다 할 일
1) 구현
2) 검증: 실제로 실행해서 확인해 줘.
   - 수집기: 샘플 모드로 전체 파이프라인이 끝까지 도는지
   - 점수 로직: docs/SCORING.md의 예시 계산과 같은 결과가 나오는지 테스트로 확인
   - 화면: 휴대폰 화면 크기(아이폰, 안드로이드)로 띄워 스크린샷을 찍어 보여 줘
   - 알림: 미리보기 메시지 내용 확인
3) docs/ROADMAP.md의 해당 항목에 체크하고 커밋, 푸시
4) 한 줄 보고 후 내 확인을 기다리지 말고 다음 마일스톤으로 진행

## 6. 세션이 끝나기 전에
- docs/API_SETUP.md를 작성해 줘 (나중에 API를 추가할 때 쓸 문서):
  필요한 키 목록, 발급 사이트와 절차, 등록할 위치와 이름, 등록 후 확인 방법,
  소스별 "미검증" 실제 구현 목록과 첫 실행 때 확인할 점.
- docs/PROGRESS.md를 작성해 줘: 완료한 것, 검증 결과, 남은 것, 알려진 문제,
  내가 대신 정한 미결 사항, 다음 세션의 첫 작업 지시문.
- docs/USER_GUIDE.md를 작성해 줘: 휴대폰에 설치하는 법(홈 화면 추가 등),
  화면 보는 법, 매일 자동 실행이 돌고 있는지 확인하는 법.
- 마지막 보고에는 "샘플 데이터로 동작 확인한 것"과 "실제 데이터로는 아직 확인 못 한 것"을
  구분해서 알려 줘.
